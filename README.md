# route-666
A 2D endless runner made in Godot, inspired by the Chrome dinosaur game and the opening car chase from the Supernatural pilot.

## How to Play
**Jump** with W/Space/Up arrow/Numpad 8
Survive as long as you can and keep the gap between you and the Impala AKA Baby
Game over IF Baby catches YOU


Made by Qtrocious for Hack Club's Haven Jumpstart
Inspired by Supernatural and the Chrome offline dino game
